# Food Delivery Mobile App UX Design

## Cognevance Technologies – Level 2 Intermediate Task

### Project Overview

A complete mobile UX design for a food delivery application. The project focuses on creating a simple, convenient, and user-friendly experience from discovering food to ordering and tracking delivery.

### Project Objective

The objective was to design a complete food delivery experience that allows users to:

- Discover food and restaurants
- Compare restaurant information
- Select food items
- Manage the cart
- Choose a payment method
- Place an order
- Track delivery status

### UX Design Process

- User Research
- User Pain Point Identification
- User Persona
- User Journey Map
- Low-Fidelity Wireframes
- High-Fidelity UI Design
- Interactive Prototype
- Usability Testing
- Project Documentation

### App Screens

The final design includes:

1. Onboarding
2. Home
3. Restaurant Details
4. Cart
5. Checkout & Payment
6. Order Confirmation & Tracking

### Main User Flow

*Onboarding --> Home --> Restaurant Details --> Cart --> Checkout & Payment --> Order Confirmation & Tracking*

### Design Features

- Simple navigation
