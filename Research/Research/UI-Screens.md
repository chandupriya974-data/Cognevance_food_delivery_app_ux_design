# High-Fidelity UI Screens

## Food Delivery Mobile App UX Design

The low-fidelity wireframes were transformed into 
high-fidelity mobile UI screens using Figma. 
The design uses a clean and modern visual style with clear
typography, food imagery, rounded components, and an 
orange primary color.

### 1. Onboarding

The onboarding screen introduces the food delivery
app and guides users to start their ordering journey.

**Main elements:**
- Food image
- App introduction
- App introduction
- Get Started button
- Page indicators

## 2. Home

The home screen helps users discover food and restaurants
quickly.

**Main elements:**
- Greeting and subtitle
- Search bar
- Food categories
- Popular restaurants
- Restaurant ratings and delivery information
- Bottom navigation

### 3. Restaurant Details

The restaurant details screen provides information
about the selected restaurant and available food items.

**Main elements:**
- Restaurant image
- Restaurant name
- Rating and cuisine
- Delivery time
- Price information
- Popular food items
- Add to cart buttons

### 4. Cart

The cart screen allows users to review their selected items before checckout.

**Main elements:**
- Food images
- Item quantities
- Quantity controls
- Subtotal
- Delivery fee
- Total amount
- Proceed to checkout button

### 5. Checkout & Payment

The checkout screen allows users to confirm their delivery
information and payment method.

**Main elements:**
- Delivery address
- Payment methods
- Order summary
- Total amount
- Place Order button

### 6. Order Confirmation & Tracking

The confirmation screen provides order details
and delivery status after placing an order.

**Main elements:**
- Order confirmation message
- Order number
- Ordered items
- Total amount
- Delivery status
- Estimated delivery time
- Track order button

### Visual Design

The UI follows a clean and modern design approach.

**Primary color:** Orange

**Background:** White

**Typography:** Clear and readable

**Components:** Rounded corners and simple layouts

**Imagery:** Food Photography

### Complete UI Flow

**Onboarding --> Home --> Restaurant Details --> Cart --> Checkout & Payment --> Order Confirmation & Tracking**

### Design Goal

The high-fidelity UI was designed to provide a simple, clear, and convenient food ordering
experience while maintaining consistency across all screens.
