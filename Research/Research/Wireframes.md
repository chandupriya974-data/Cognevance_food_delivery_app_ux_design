# Low-Fidelity Wireframes

## Food Delivery Mobile App UX Design

The low-fidelity wireframes were created to establish
the basic layout, content hierarchy, navigation, and user flow
before developing the high-fidelity UI design.

### 1. Onboarding

The onboarding screen introduces the food delivery app
and guides the user to begin the ordering experience.

**Main elements:**
- Food image
- App introduction
- Get Started button
- Page indicators

### 2. Home

The home screen allows users to search for
food, browse categories, and discover popular
restaurants.

**Main elements:**
- Greeting
- Search bar
- Food categories
- Popular restaurants
- Bottom navigation

### 3. Restaurant Details

The restaurant details screen provides information
about the selected restaurant and its food items.

**Main elements:**
- Restaurant image
- Restaurant name
- Rating and cuisine
- Delivery time
- Food items
- Add to Cart buttons


## 4. Cart

The cart screen allows users to review their
selected food items and order total.

*Main elements:*
- Selected food items
- Quantity controls
- Subtotal
- Delivery fee
- Total amount
- Proceed to checkout button

### 5. Checkout & Payment

The checkout screen allows users to confirm
their delivery address and select a payment method.

*Main elements:*
- Delivery address
- Payment methods
- Order summary
- Total amount
- Place Order button

### 6. Order Confirmation & Tracking

The order confirmation screen confirms the order
and provides delivery tracking information.

*Main elements:*
- Order confirmation
- Order number
- Ordered items
- Total amount
- Delivery Status
- Estimated delivery time
- Track Order button

### Wireframe Flow
*Onboarding --> Home --> Restaurant Details --> Cart --> Checkout & Payment  --> Order Confirmation & Tracking*

### Purpose

The wireframes helped define the structure and user flow of the application
before applying colors, images, typography, and other visual design elements.
